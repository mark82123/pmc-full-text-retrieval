Word Embedding — CBOW 與 Skip-gram（word2vec）

以 1,000 篇 PubMed 摘要（GLP-1）訓練詞嵌入：ir/word2vec.py 純 Python 自行實作，negative sampling、dynamic window、高頻詞 subsampling、線性遞減學習率； ir/tsne.py 實作 PCA（power iteration）與 t-SNE。Skip-gram 以中心詞預測視窗內的每個周圍詞；CBOW 以視窗內詞向量的平均預測中心詞。 下方依作業流程排列：前處理與詞彙表 → 訓練樣本 → 訓練（多組模型並存）→ 相似度分析 → PCA / t-SNE 視覺化 → 參數、低頻詞與穩定度。

2. 產生訓練樣本（context window）

同一個句子，固定視窗 ±w 時 Skip-gram 產生「(中心詞 → 每個周圍詞)」配對，CBOW 產生「(周圍詞集合 → 中心詞)」樣本。訓練時實際視窗 b 由 1..w 均勻抽出（dynamic window），所以近的詞被取用的機率較高。點句中的詞只看該位置的樣本。

3. 訓練詞嵌入模型

每組設定存成 data/w2v/<name>.json，可同時保留多個模型互相比較。工作排入佇列後逐一在背景訓練（純 Python：Skip-gram 50 維 10 epochs 約 4–5 分鐘，CBOW 約 1.5 分鐘）。

4. CBOW vs Skip-gram

為什麼 Skip-gram 對罕見詞 / 專業術語特別有用？

Skip-gram 把每一次出現都拆成 2b 個獨立的訓練配對，罕見詞自己的向量每出現一次就被更新 2b 次（每次還帶 k 個負樣本的梯度）；CBOW 把視窗內的詞平均後才預測中心詞，罕見詞的向量只分到平均梯度的 1/2b，而且它的訊號被同視窗的高頻詞稀釋。 因此在同樣的語料下，Skip-gram 對出現 5–20 次的專有名詞（藥名、基因、量表縮寫）通常學得比較穩，代價是訓練配對數多、速度慢；CBOW 對高頻詞的統計更平滑，訓練快，適合大語料。下方第 8 節用「同詞幹變形是否互為近鄰」與「兩個 seed 的近鄰重疊率」實際量測。

6. 詞嵌入是否具有語意？相關詞組的餘弦相似度矩陣

以分號分組、逗號分詞。若模型學到語意，組內平均相似度應明顯高於組間；「隨機詞對」是整個詞彙表中任抽 400 對的平均，當作基準線（小語料的向量空間常有共同方向，隨機詞對的 cosine 不會接近 0）。

7. 視覺化：PCA 與 t-SNE 降到二維

同一組詞、同一個模型，左 PCA（線性：前兩個主成分）、右 t-SNE（非線性：保留鄰域機率分布）。輸入 1–6 個種子詞會畫出每個種子與其最近鄰（顏色 = 所屬種子）；留空則畫最常見的 N 個詞。 k-NN 保留率：每個點在原始 50 維空間的 k 個最近鄰，有多少仍是它在二維圖上的 k 個最近鄰——圖上看起來成群不等於模型語意好，這個數字衡量的是「圖」有多忠於向量空間。

8. 參數影響、低頻詞表現與穩定度

沒有外部標準答案時的內在評估：把詞彙依出現次數分桶，對每桶抽樣 120 個詞，計算 sim@k（前 k 個近鄰的平均 cosine，越高表示鄰域越緊）、近鄰頻次中位數（罕見詞的鄰居是罕見詞還是常見詞）、 變形命中率（同一個 Porter 詞幹的其他詞形——patient / patients、treat / treated——是否出現在前 k 名；只計算有變形存在的詞）； 近鄰重疊率（兩個模型對同一個詞的前 k 近鄰的 Jaccard）用來比較架構、參數，或同設定不同 seed 的穩定度。

Edit distance — 動態規劃

D[i][j] = 把字串 a 的前 i 個字元變成 b 的前 j 個字元所需的最少編輯次數： D[i][j] = min( D[i-1][j] + 1 (刪除), D[i][j-1] + 1 (插入), D[i-1][j-1] + [ai ≠ bj] (取代／相同) )， 另加 Damerau 擴充：相鄰兩字元對調算一次（D[i-2][j-2] + 1）。右下角即為距離；反白格子是回溯得到的一條最佳路徑。

Spelling correction — 拼字校正

字典是語料中所有出現過的詞（小寫原形）及其 collection frequency。流程： ① 用字元 bigram 索引篩出候選（k 次編輯最多破壞 3k 個 bigram，共享 bigram 不足者不可能在距離內）； ② 對候選以帶狀 (banded) DP 計算編輯距離，超過 k 即提前中止； ③ 以（距離小 → 語料頻率高）排序。短字（≤4 字元）k = 1，其餘 k = 2。

在 Search 分頁：查詢詞不在語料中時顯示 Did you mean；若原查詢沒有任何結果，會自動改用校正後的查詢。 也可以用 word~ 或 word~2 做模糊比對（partial matching）：展開成編輯距離內的所有詞。

規則只有一條：連續的字母或數字是一個 token，其餘字元（連字號、撇號、括號、標點）都是分隔符，接著全部轉小寫。
        這讓 T-cell、T cell 都能互相匹配，但也有代價——下面的反例都是這個系統真實的行為：

      

        
US、WHO、IT小寫後變成 us、who、it，正好是停用詞而被整個丟掉。查 "WHO guidelines" 只剩 guidelines。

經典清單有兩個常見來源：SMART 系統（Salton, 1971）的 571 字清單，以及 Snowball 詞幹器專案附帶的 174 字英文清單（NLTK 內建的就是這份）。

3. Porter 詞幹演算法（1980）：五個步驟

      
核心概念是 measure m：把字寫成 [C](VC)m[V] 的形式，m 是「母音串接子音串」的次數，例如 m(tr)=0、m(trouble)=1、m(troubles)=2。每條規則都要求去掉字尾後剩餘部分的 m 夠大，避免把短字砍壞（rate 不會變 rat）。

      

        
步驟規則例子

        
1a複數：sses→ss、ies→i、s→(去掉)；ss 不動patients→patient、therapies→therapi、class→class

        
1b去 -ed / -ing（剩餘部分須含母音），再修補結尾：at/bl/iz 補 e、雙子音變單、cvc 補 egeneralized→generalize、hopping→hop、filing→file

        
1c結尾 y→i（剩餘部分含母音）therapy→therapi、happy→happi

        
2m>0 時長字尾對應：ational→ate、ization→ize、iveness→ive、biliti→ble …organization→organize、sensitiviti→sensitive

        
3m>0 時：icate→ic、ative→(去)、alize→al、ical→ic、ful / ness→(去)generalize→general、analytical→analytic

        
4m>1 時直接砍字尾：ement、ance、ence、able、ment、ant、ent、ism、ate、iti、ous、ive、ize、ion(前面須為 s/t)、al、er、ic、ougeneral→gener、organize→organ、adjustment→adjust

        
5a / 5b去掉結尾 e（m>1，或 m=1 且非 cvc）；ll→l（m>1）activate→activ、controll→control

  2. Tokenization 斷詞ⓘ – 以連續的字母/數字為單位；連字號會切開（COVID-19 → covid、19）。
    3. 
        
  3. Normalization 正規化 – 轉小寫、移除 191 個 stop word、以 Porter stemmingⓘ 取詞幹（自行實作 1980 年的演算法）。

    6.

  7. Ranking 排序 – Okapi BM25ⓘ（k1 = 1.5、b = 0.75），或 TF-IDFⓘ，或單純命中次數；標題中的命中乘以 1.25 倍加權。
    8. 
        
  8. Presentation 呈現 – 以最相關的句子作為 snippetⓘ、關鍵字反白、命中位置分布圖 (match map)、詞頻圖表與文件統計。
    9. 
      


      
句子偵測 (EOSⓘ) – 規則式方法

      
候選的句子邊界為 . ! ?（或刪節號）加上可有可無的右引號/右括號，之後接空白。符合以下任一情況時不會切句：

      
    
        
  • 下一個字元是小寫字母（句子應以大寫、數字、括號或符號開頭）；
    • 
        
  • 句號前的詞是已知縮寫ⓘ（e.g., i.e., et al., Fig., Dr., vs., approx., No., Ref., Eq., Vol., Jan.…）；
    • 
        
  • 句號前的詞只有一個字母（人名縮寫 J. R. Smith、屬名 E. coli）或是帶點的縮寫（a.m.、U.S.）；
    • 
        
  • 句號夾在數字之間（0.05）— 後面沒有空白，根本不會成為候選。
    •

統計指標說明

      

        
Characters字元數（含空白）；另有不含空白的版本

        
Tokens / Wordstoken 為字母或數字的連續片段；word 只計純字母的 token（不含 2020、19 這類數字）

        
Unique words轉小寫後不重複的 word 數量

        
Index terms / Unique terms經 stop word 移除與 stemming 後留下的索引詞數量／不重複詞幹數量

        
Sentences規則式 EOS 偵測得到的句數；naive 為基準值

        
Lexical diversity詞彙多樣性ⓘ = unique terms ÷ index terms

        
df / cfdfⓘ = 含此詞的文件數；cfⓘ = 此詞在全語料庫的總出現次數
