3. 實作 TF、DF、IDF、TF-IDF 與 Cosine Similarity

學習目標 1。

因沿用 Project #3 的 ir/tfidf.py（tf、df、idf = ln(N/df)、ltc 權重、L2 正規化，分數 = 內積 = cosine），並以 WordTokenizer 讓它用與詞向量完全相同的詞（不 stemming）。
果搜尋結果上方的查詢分析條會列出每個詞的 df 與 idf；df 高的詞 idf 必低（said df 2,026 → idf 0.49；petroleum df 90 → 3.60）。TF-IDF 方法的 cosine 分數在 0–1 之間，且「scored documents」只會是含查詢詞的文件數（例如 c03 只有 284 篇），因為 TF-IDF 沒有詞就沒有分數——這正是它的本質。
  1. 第 4 節 方法選 A tfidf，查詢 petroleum production and output：查詢條顯示 petroleum df 90 · idf 3.60，production df 180 · idf 2.91，output df 92 · idf 3.58；摘要列顯示「284 of 3,299 documents scored」。
  2. 第 1 節右側「test 集合 df 最高的詞」：said、mln、dlrs 的 df 最大 → 這些詞在 TF-IDF 中權重最低（RQ 文字有引用）。
  3. 對照 Project #3 分頁（/#vsm）可看到 tf / idf 曲線與公式。

5. 列出每個詞的 Top-5 Nearest Neighbors，並回答三個問題

規格：「哪些鄰近詞具有合理的語意或使用情境關係？哪些是因為常出現在相似新聞情境？哪些不符合預期，原因為何？向量相近不代表同義。」

因第 3 節對每個詞在每個模型算 cosine 最高的 5 個詞，並為每個鄰近詞附上三個證據：同篇（train 中共同出現的文件數）、PMI、鄰近詞最常帶的主題；另有詞對 cosine 表。
果三個問題各自對應到可觀察的證據：(1) 合理語意 → 同主題且 cosine 高（oil → crude）；(2) 情境共現 → 同篇多、PMI 高、但不是同義（opec → lukman、nazer）；(3) 不符預期 → 稀有詞（count < 40，兩模型 Top-5 零重疊：cereal、tariff）或語料用法偏移（petroleum → 公司名）。詞對表中 profit / loss、rise / fall 的 cosine 高於 0.75，直接驗證「相近 ≠ 同義」。
  1. 開啟 第 3 節，按 Nearest neighbours（預設 16 個詞、兩個模型）。
  2. 看 oil：Top-5 含 crude、gas、petroleum，標「同主題」且主題欄為 crude → 問題 (1)。
  3. 看 opec（skip-gram）：lukman、nazer、ceiling 標「情境共現」，同篇 6–42、PMI 3.8–4.7 → 問題 (2)。
  4. 看 petroleum：鄰近詞是 king / xon / esso（skip-gram）或 mines / columbia / mining（CBOW），主題欄多為 acq；頂端主題色條顯示含 petroleum 的文件只有 44% 是 crude → 問題 (3) 的原因就在證據裡。看 cereal：count 24、標「稀有」、兩模型共同鄰居 0 / 5。
  5. 下方詞對表：profit–loss 0.79、rise–fall 0.87、buy–sell 0.77 → 反義卻相近。

若不符：只看到 cosine 沒有證據欄，就無法區分「同義」與「同情境」——這是老師特別提醒的誤解。

6. 使用訓練完成的詞向量表示文件（方法 A、B、C、D）

學習目標 4；老師指定的核心比較：方法 A TF-IDF、方法 B TF-IDF Weighted Word Embedding。

因ir/embedding.py：A TF-IDF；C 詞向量平均；B Σ (1+ln tf)·idf·v 加權平均；D α·cosA + (1−α)·cosB。四者使用同一組詞、同一 cosine；OOV 詞跳過並報告覆蓋率。
果(a) 嵌入法對每一篇文件都有向量 → 摘要列顯示「3,299 of 3,299 documents scored」（TF-IDF 只有含詞的文件）；(b) 查詢條會標出 OOV 詞；(c) B 的查詢詞權重與 idf 成正比（petroleum 3.60 > output 3.58 > production 2.91）；(d) 第 2 節覆蓋率：46% 詞型 / 93% 詞元 → 多數 OOV 是只出現一次的專有名詞。自動核對
  1. 第 4 節 方法下拉選單應有五個選項：A₀ tfidf-stem、A tfidf、C w2v-avg、B w2v-tfidf、D hybrid。
  2. 選 B 查 petroleum production and output：摘要列「3,299 of 3,299 scored」，查詢條顯示 query word weights 與 idf 一致。
  3. 查一個全 OOV 的字串（例如 zyxwv）：出現「no query word is in the embedding vocabulary → empty ranking」。
  4. 第 2 節模型表的 coverage 欄出現 46.0% / 93.0%（第一次使用後）。

9. 核心比較：方法 A TF-IDF vs 方法 B TF-IDF 加權詞向量

老師：「這個比較能回答：保留 TF-IDF 對重要詞的辨識力，同時引入上下文表示，是否能改善文件檢索？若沒有改善，也是有價值的發現。」

因20 個查詢刻意分成四種用字（主題詞 / 路透慣用詞 / 同義改寫 / 情境描述），讓「查詢用字離文件詞彙多遠」成為可控變因。
果若詞向量的價值在於語意匹配，則 B 的優勢應隨用字距離增加而放大，在主題詞查詢上則與 A 持平。實測（skip-gram d100）：主題詞 0.92 vs 0.92；慣用詞 0.92 → 0.94；同義改寫 0.64 → 0.80；情境描述 0.44 → 0.80。整體 P@10 0.730 → 0.865、MRR 0.824 → 0.942、nDCG@10 0.605 → 0.735；逐題 B 勝 9、A 勝 5、平手 6。自動核對
  1. 第 6 節「P@10 by query kind」表：沿 A tfidf 那一列由左往右讀，數字遞減；B 那一列幾乎持平。
  2. 第 5 節 按「A vs B（核心）」預設實驗，查詢 petroleum production and output：A 的 P@10 0.20（前 10 名多是工業產出 ipi、併購）、B 0.80；overlap@k 只有 0.2。
  3. 反例也要看：查 cereal crop production forecast 或 import tariffs and export restrictions，A 反而較好（cereal / tariff 是稀有詞、向量不穩）。
  4. 第 7 節 RQ3 以目前數據寫出 A vs B 的結論，含「不能推論詞向量一定較好」。

10. 不預設 Skip-Gram 優於 CBOW；參數影響

老師：「不必預設 Skip-Gram 一定優於 CBOW。兩者的效果受資料量、詞頻、參數設定與訓練方式影響。」

因六個模型（sg / cbow × d50 / d100、sg 視窗 2、cbow 10 epochs）在同一份 train 訓練、同一組查詢評估；第 6 節可任意勾選模型並列。
果若架構是唯一因素，所有 sg 應一致優於所有 cbow，且訓練越久越好。實測不是：sg d100 B 方法 P@10 0.865 vs cbow 0.790，但 cbow 10 epochs（0.770）比 5 epochs 更差、sg 視窗 2 掉到 0.800、sg d50（0.885）不輸 d100——所以差距受參數左右，結論只能說「在此語料與參數下 skip-gram 較好」。詞層級 Top-5 兩架構只重疊 1–3 個，但文件層級差距小得多（文件向量把個別鄰居差異平均掉了）。
  1. 第 6 節 勾選全部六個模型 → Evaluate，看 B 方法六列的 P@10 排序是否如上。
  2. 第 3 節每個詞卡片底部的「neighbours shared by all 2 models: n / 5」：多數是 1–3。
  3. 第 7 節 RQ4 由勾選的模型即時產生逐題勝負（sg 勝 / CBOW 勝 / 平手）。

11. 分析 TF-IDF 與 Word Embedding 在詞彙匹配、語意相似度、文件排序上的差異（word-level 與 document-level 分開）

學習目標 7；老師：「不要只比較詞向量相似度……只有 document-level 才直接回答 IR 的問題。」

因分頁刻意把 word-level（第 3 節）與 document-level（第 4–6 節）分開，第 7 節 RQ1–RQ5 由即時數據生成，第 5 節提供「詞彙重疊」與「無查詢詞」兩個欄位量化語意匹配。
果詞彙匹配：A 的前 10 名詞彙重疊必定 > 0、「無查詢詞」永遠 0；語意匹配：B 的「無查詢詞」可 > 0（c03 有 2 篇），這些文件若相關就是收益、不相關就是誤配（鋅、鋁產量）；文件排序：overlap@k 與 Kendall τ 顯示 A、B 的前 10 名重疊常不到一半。加權的因果（C vs B）：不加權時 said、mln 把文件向量拉向同一方向 → MRR 下降（0.912 vs 0.942；CBOW 0.762 vs 0.870）。
  1. 第 5 節 按「C vs B（加權）」與「A / B / D（融合）」：看詞彙重疊、無查詢詞、overlap@k 三欄。
  2. 第 7 節：RQ1（詞層級）、RQ2（詞彙 vs 語意）、RQ3（A vs B）、RQ4（架構）、RQ5（加權與融合、限制）五段都由目前數據填入，改變第 6 節的勾選後文字會更新。
  3. α 掃描：D 在 α = 0.2 最佳（nDCG@10 0.757），預設 0.5 反而比純 B 差 → 融合權重不能假設。
