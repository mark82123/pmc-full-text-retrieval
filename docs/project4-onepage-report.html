任務一資料集、相關性判斷、TF / DF / IDF / TF-IDF 與 cosinespec 1–3

資料。自行解析 22 個 SGML 檔（21,578 則 1987 年新聞）。ModApte = TOPICS="YES" 且 LEWISSPLIT TRAIN / TEST → train 9,603 篇（68K 句、763K 詞元）只用來訓練 word2vec；test 3,299 篇（平均 74.5 詞、詞彙 17,295）是檢索集合。 相關性：每個查詢針對一個主題，test 文件帶該主題即相關（唯一主題 = grade 2，否則 grade 1）；TOPICS 由路透編目員指派，與查詢字和方法無關。

TF-IDF。沿用 Project #3 的向量空間模型：tf(t,d)、df(t)、idf = ln(N/df)，ltc 權重 (1+ln tf)·idf 後 L2 正規化，分數 = 內積 = cosine。TF-IDF 與詞向量使用完全相同的詞（小寫、去停用詞、不 stemming）；Porter-stemmed 的 Project #3 管線另列為 A₀ 對照。 df 越大 idf 越小：said df 2,026 → idf 0.49、mln 1,609 → 0.72、dlrs 1,451 → 0.82；petroleum df 90 → 3.60、output 92 → 3.58、production 180 → 2.91。TF-IDF 只對含查詢詞的文件打分（c03 只有 284 / 3,299 篇有分數），這也是後面 MAP 偏低的原因。

C 詞向量平均：d = Σt tf·v(t) / Σ tf
B TF-IDF 加權平均：d = Σt (1+ln tf)·idf·v(t)，L2 正規化

每篇文件都有向量（3,299 / 3,299 篇有分數）；B 讓 said、mln 等高 df 詞幾乎不拉動文件向量；OOV 詞跳過並回報覆蓋率。

D 融合：score = α·cosA + (1−α)·cosB（預設 α = 0.5，掃描 0–1）

查詢向量用同一公式；B 的查詢詞權重與 idf 成正比。檢索系統：查詢 → 前處理 → 建向量 → 與每篇 test 新聞算 cosine → 排序 → 前 k 名；每筆列出 TOPICS、rel 等級、查詢詞是否命中、查詢詞在文件中最相近的詞（可解釋為何配到）。

結論差異分析：詞彙匹配、語意相似度、文件排序spec 9–11 · RQ1–RQ5

  • 核心比較 A vs B（spec 9）。保留 TF-IDF 對重要詞的辨識力、再引入上下文表示有改善：skip-gram P@10 +18%、MRR +14%、nDCG@10 +21%；但收益全部來自用字與新聞不同的查詢（同義改寫 .64 → .80、情境描述 .44 → .80），主題詞與慣用詞查詢持平（.92）。c03 petroleum production and output：A .20 → B .80（前十重疊只 2 篇）。反例：g03 cereal（.8 → .7）、t03 tariff（.9 → .7）——稀有查詢詞的向量不穩定時，字面比對反而較好。
  • CBOW vs skip-gram（spec 10）。同參數下 skip-gram 較好（B 方法 .865 vs .790；逐題 7 : 2 : 11），但不是架構決定一切：CBOW 10 epochs 反而退步（loss 1.95 → 1.65，P@10 .790 → .770）、skip-gram 視窗 2 掉到 .800、d50 不輸 d100（.885）；詞層級 Top-5 兩架構只重疊 1–3 個，文件層級差距卻小得多（文件向量把鄰居差異平均掉）。小語料上差距受資料量、詞頻與參數左右，結論只能是「在此語料與參數下 skip-gram 較好」。
  • 詞彙匹配 vs 語意相似度 vs 排序（spec 11）。詞彙匹配：A 的「無查詢詞」結果永遠 0；語意匹配：B 可排進不含任何查詢詞的文件（c03 有 2 篇，如 API 庫存週報），相關就是收益、不相關就是誤配（鋅、鋁產量）；排序：A 與 B 前十重疊常不到一半。加權的因果：不加權的 C 讓 said、mln、dlrs 把所有文件拉向同一方向（MRR .912 vs B .942；CBOW .762 vs .870）。融合 D 在 α = .2 最佳（nDCG@10 .757），預設 α = .5 反而比純 B 差——融合權重不能假設。
  • 限制。加權平均不保留詞序與否定；相關性只來自 TOPICS；20 題，差距 < .05 不顯著；詞向量只用 train 訓練（test 詞型 OOV 54%）；結論限於小型新聞語料——Word Embedding 不保證優於 TF-IDF，必須以 document-level 的檢索評估驗證。
