RQ2為什麼 IDF 能降低常見詞的重要性、提高具辨識力詞項的權重？

A3　① tf 與 ② df 的關係：都取 log，但方向與層級不同

相同：1 + ln tf 與 ln(N / df) 都是「對一個計數取對數」，背後同一個想法：計數加倍，證據不該加倍。

不同：tf 是局部量（這篇文件裡的次數），權重隨 tf 遞增，回答「這篇在講它嗎」；df 是全域量（整個語料出現在幾篇），權重隨 df 遞減，回答「這個詞能區分文件嗎」。兩者各自獨立，所以 SMART 放在不同位置相乘；log tf 把 tf 壓到與 idf 同一量級，idf 的效果才顯現（RQ2）。

怎麼讀數據

  • P@k：前 k 名裡相關的比例；與相關集大小無關，相關集大的題容易拿 1.0。
  • R@k：前 k 名找回了相關集的幾分之幾，被相關集大小封頂（見上註）。
  • RR / MRR：第一篇相關文件名次的倒數；1.0 = 第 1 名就相關。
  • AP / MAP：每找到一篇相關文件就量一次 precision 再平均，相關文件排得愈前愈高；跨題、跨 scheme 比較的主指標。
  • nDCG@10：分級版，grade 2 比 grade 1 值錢，名次愈後折扣愈重；grade 2 排在前面才高。
  • overlap@10 / Kendall τ：兩個 scheme 前 10 名的交集比例與名次一致性；τ ≈ 0 表示榜單幾乎重排。
  • mean length：前 10 名平均索引詞數（全集合 211）；偏高 = 偏好長文件（RQ4）。
  • 讀表範例：q03 AP nnn 0.19 → ltn 0.53，是 idf 把 cardiovascular 拉過 glp / receptor / agonist（RQ2）；q09 三者都只有 0.31，nausea、vomiting 幾乎每篇試驗都提到，標籤卻只標以此為主題的文章，是文字訊號與標籤分歧最大的一題；q15 ltc 0.44 > ltn 0.36，短查詢在正規化後較不被長文件淹沒；q14 是唯一 log tf 沒幫上的題（0.65 對 0.66）。

C2　BM25 怎麼處理資料

score(q, d) = Σt∈q qtft · idf(t) · tf · (k₁ + 1) / tf + k₁ · (1 − b + b · |d| / avgdl)
k₁ = 1.2，b = 0.75，avgdl = 211；idf(t) = ln(1 + (N − df + 0.5) / (df + 0.5))；查詢端用原始 qtf、不正規化

  • tf 飽和（取代 SMART 第 ① 位）：權重有上限 k₁ + 1 = 2.2，壓得比 1 + ln tf 更兇。tf = 1 → 1.00、5 → 1.77、30 → 2.12（log 給 2.61、4.40）；「出現幾次」幾乎退化成「有沒有出現」，接近 b（布林）與 l 之間。
  • 長度正規化（取代第 ③ 位）：分母的 k₁ 項乘上 (1 − b + b·|d|/avgdl)。b = 0 完全不管長度（= n），b = 1 完全按長度打折；0.75 是「部分正規化」。兩倍長的文件 tf = 5 只剩 1.55，一半長的升到 1.91。它懲罰長度的方式是「同樣的 tf 在長文件裡算少一點」，不是 cosine 的「整支向量除以長度」。
  • 機率型 idf（取代第 ② 位）：ln(1 + (N − df + 0.5)/(df + 0.5)) 與 ln(N/df) 幾乎重合（df 1 → 7.60 vs 8.01，df 100 以上完全相同），且不像 p（prob idf）會把過半文件出現的詞歸 0。
