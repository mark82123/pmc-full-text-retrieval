idf = ln(N/df) 隨 df 單調下降（df 1 → 8.01，1,000 → 1.10，N → 0）。出現在八成文件的詞對「這篇 vs 那篇」沒有資訊：對每篇都加同樣分數不改變排名，只讓分數被它的 tf 噪音淹沒。 q03「GLP-1 receptor agonists and cardiovascular outcomes」沒有 idf 時前五名由 glp/receptor/agonist 重複最多的文件決定（腎臟、酒精、脫髮…無一相關）；有 idf 後 cardiovascular 的權重是 glp 的 6 倍，排名才轉向心血管。整體 lnn → ltn MAP 0.533 → 0.615（+15%）；只用 idf（btn）就有 0.519，nDCG@10 甚至最高（0.620）：短文本裡「有無出現」比「出現幾次」更重要。

方法與限制相關性判斷

資料集沒有現成標籤，依作業指示用主題標籤：每個查詢定義若干概念群（正規表示式），文件的每一群至少命中一個 MeSH 標題或作者關鍵詞即相關，命中 major-topic MeSH 為 grade 2；只看標籤不看文字，故不偏向任何 weighting，並可在介面手動覆寫。限制：163 篇（5.4%）無任何標籤（另提供 condensed-list 評估，各值 +0.01～0.03、排序不變）；最新記錄 MeSH 尚未完成（57% 有 MeSH）；規則由作者撰寫而非獨立評審；標籤層級的相關比人工判讀寬鬆，相關集偏大、R@k 絕對值低。另一觀察：純數字 token（佔詞彙 11.5%）df 小、idf 高，會混入 ltn 向量前列；移除數字是最直接的 modified TF-IDF。
