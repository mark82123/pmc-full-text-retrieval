1資料、模型與四種文件表示

Reuters-21578（22 個 SGML 檔、21,578 則 1987 年新聞）自行解析：實體解碼、移除控制字元與 "Reuter" 署名、硬換行段落接回句子。ModApte = TOPICS="YES" 且 LEWISSPLIT TRAIN／TEST。train 9,603 篇（68K 句、763K 詞元）訓練 word2vec（negative sampling、dynamic window；skip-gram d100 5 epochs 21 分鐘、CBOW 6.7 分鐘）；test 3,299 篇是檢索集合（平均 74.5 詞、詞彙 17,295）。

所有方法用同一組詞（小寫、去停用詞、不 stemming）與 cosine：A TF-IDF ltc；C 詞向量平均 Σ tf·v；B TF-IDF 加權平均 Σ (1+ln tf)·idf·v；D α·cosA + (1−α)·cosB；A₀ = Project #3 的 Porter-stemmed TF-IDF（對照）。

相關性：查詢針對一個主題，test 文件帶該主題即相關（grade 2 = 唯一主題）。TOPICS 由路透編目員指派，與檢索方法無關。

4研究問題的結論

  • RQ1 詞層級。接近有三種來源——同語意場／同句型、同一類新聞的共現、稀有詞雜訊——要用同篇數、PMI 與主題分布才分得開；反義詞 cosine 高達 .77–.92，向量相近不代表同義。
  • RQ2 詞彙 vs 語意匹配。主題詞與慣用詞查詢 TF-IDF 與 B 同為 .92；同義改寫 .64 → .80、情境描述 .44 → .80。stemming（A₀）是 TF-IDF 自己的有限語意匹配（.44 → .56）。語意匹配的代價：情境相近但主題不同的誤配（鋅、鋁產量）、稀有查詢詞的不穩定向量（t03 .9 → .7）。
  • RQ3 核心 A vs B。skip-gram：P@10 +18%、MRR +14%、nDCG@10 +21%，收益全在用字不同的查詢；CBOW 收益減半。這不是「詞向量一定較好」：C · CBOW 的 MRR（.762）低於 TF-IDF（.824）。
  • RQ4 CBOW vs skip-gram。5 epochs 下 skip-gram 較好（逐題 7 : 2 : 11）；但 CBOW 10 epochs 反而退步（loss 1.95 → 1.65，P@10 .790 → .770）、skip-gram 視窗 2 退到 .800、維度 50 / 100 幾乎無差（sg-d50 .885）。763K 詞元的小語料上差距受參數與 seed 左右，不應預設 skip-gram 必勝；詞層級 Top-5 只重疊 1–3 個，但文件層級差距小得多——文件向量把個別鄰居的差異平均掉了。
  • RQ5 加權與融合。不加權平均 C 讓 said、mln、dlrs 把所有文件拉向同一方向（MRR .912 vs B .942；CBOW .762 vs .870）；融合在 α = .2 最佳（nDCG@10 .757），預設 α = .5 比純 B 差。限制：加權平均不保留詞序與否定；相關性只來自 TOPICS；每主題 4 題、共 20 題，差距 < .05 不應視為顯著；結論限於小型新聞語料。

前處理（所有方法相同）：WORD_RE 取字母開頭、可含連字號的詞 → 小寫 → 移除停用詞與單字母 → 純數字丟棄；不做 stemming（A₀ 除外）。

A w(t,d) = (1 + ln tf)·ln(N/df)，查詢同；兩側 L2 正規化 → 內積 = cosine。C d = Σ tf·vt / Σ tf。B d = Σ (1+ln tf)·idf·vt / Σ w；查詢 q 同式；再 L2 正規化；score = q·d。D score = α·cosA + (1−α)·cosB，兩側皆無正分的文件不檢回（α = 1 即 A）。

OOV：不在 9,996 詞彙中的詞跳過（test 詞型 54%、詞元 7%）；查詢全 OOV → 空排名。解釋：每筆結果列出查詢詞是否在文件中，以及每個查詢詞在該文件中 cosine 最高的 3 個詞（語意／情境匹配的證據）。
