RQ3PCA 與 t-SNE 的視覺化結果有何不同？

PCA　線性：投影到變異最大的兩個正交方向。PC1 + PC2 解釋 53.7% 變異；k-NN 保留率 k=5 / 10 = 50.8% / 83.1%。座標與距離有意義、可重現，但群內細節被壓扁。

t-SNE　非線性：最小化高維與低維鄰居分布的 KL 散度。k-NN 保留率 81.5% / 89.0%，局部鄰域忠實；但群間距離、群的大小與方位沒有意義，換 perplexity 或 seed 佈局就不同。

注意　四群在兩圖都分得開，主因是種子詞本來就是語料中相距最遠的主題：在未挑種子的 120 個高頻詞上，PCA 只解釋 15.4% 變異，幾乎看不出結構；t-SNE 對完全隨機的向量也會畫出「群」。視覺上成群 ≠ 語意好：判斷依據是 RQ2 的 cosine，圖只用來看「模型把誰當成鄰居」。

結論　以「只換 seed」的重疊率為尺規：視窗決定「相似」的定義，min_count 下修只會引進雜訊，維度在這個語料規模下無感。

RQ5小型語料的限制為何？

穩定度：同語料、同超參數只換 seed，Skip-gram 對同一詞的前 10 近鄰只剩 48.6% 重疊、CBOW 36.7%；5–9 次的詞 41.7% / 16.6%。罕見詞的「鄰居是誰」有一半以上由初始化決定；200+ 次的高頻詞 54–60%，也非完全穩定。

低頻詞：Zipf 長尾使 41% 詞型只出現一次、69% 不到 5 次；留下的 4,438 詞中仍有 40% 只出現 5–9 次，其 sim@10 高達 0.93–0.97：不是學得好，而是向量幾乎沒離開初始化。

專業術語：全語料僅 123 個詞超過 200 次，tumor 只有 19 次，落在不穩定區；藥名例外（semaglutide 759 次）只因語料本來就以 GLP-1 查得。

領域與資料量：單一主題讓「同主題」失去鑑別力（obesity–diabetes 0.66 反高於 diabetes–insulin 0.30），cancer 的近鄰因樣板句變成併發症（見 RQ1）。反面是優點：無一詞多義、句法規整，才能在 1.8 × 10⁵ token（比 Mikolov 的 10⁹ 少四個數量級）上學出主題群。loss 收斂不是學完了，而是能擠出的資訊就這麼多。

結論　1,000 篇摘要足以學到主題層級的嵌入：查詢擴展（semaglutide → dulaglutide / liraglutide）、同義縮寫（t2dm / t2d / mellitus）、副作用詞群；不足以支撐詞層級的精度：類比推理、罕見術語相似度。改善方向：PubMed / PMC OA 大語料預訓練再微調、fastText 子詞、或改用上下文嵌入。
